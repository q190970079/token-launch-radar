How the price is made: each category of traded protocol gives a median market-cap / TVL multiple. A pre-token protocol is priced at its TVL times that multiple, adjusted for seven-day momentum, for how long it has run while still recording no token, and for the number of chains it covers. Token-bearing protocols are set aside, never ranked, and so are wrapped, staked and bridged products of a token that already trades, exchange venues, and superseded versions. Implied value is this board's claim, not a prediction that a token will launch.
